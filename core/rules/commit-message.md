# Commit message

- One-line conventional commit: `type(scope): description`, saying only what was done; reasons and background belong in the PR description.
- Trailer: in personal / open-source repos (the origin owner is the user's own GitHub account), add the attribution the harness provides; in company, team, or uncertain-ownership repos, do not. When project rules say otherwise, follow the project.
- Do not rewrite pushed history to backfill a trailer.
