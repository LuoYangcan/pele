# Turn checkpoint

More than 3 consecutive turns on the same request and the user is still pointing out problems or expressing dissatisfaction: stop and use the question tool to clarify how the goal I understand differs from what you expect, which of my judgments went off track, and what information is still missing. More than 7 turns: go back to the original request, list the approaches tried and why each failed, diagnose whether it is a misread requirement, a wrong approach, or a wrong execution detail, and align the new direction with the user before changing anything; do not automatically discard all existing code.

Does not trigger when the user has signaled satisfaction, is only adding minor tweaks, is in pure Q&A, or explicitly says "keep trying". The count resets when the user changes topic.
